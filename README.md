# Projeto-Expotech-CaseWalle
O WALL-ECO é uma solução de automação residencial e monitoramento ambiental que une hardware customizado (case mod) e um servidor doméstico próprio. Inspirado na missão do clássico robô da ficção científica, o projeto aborda um dos maiores desafios das cidades do futuro: a triagem, o controle e a redução dos resíduos gerados dentro de casa.
